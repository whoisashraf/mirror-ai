# Mirror AI v0.2 — White-label visual workspace

## Store isolation
Mirror is infrastructure for each merchant, not a shopper marketplace. No merchant storefront contains discovery links to another merchant. The platform root is B2B-facing.

## Tenant resolution
1. Resolve a configured custom hostname when present.
2. Otherwise resolve `/store/:slug` for hosted pilots.
3. Apply merchant `storefront_config` to the shopper UI.

## Persistent visual conversation
The current generated look stays in a persistent image pane while chat continues beside/below it. A complete-look generation updates that pane without resetting chat.

## Chained generation
Every generated look may reference `parent_generation_id`. For an edit, the backend supplies:
- previous generated look as CURRENT LOOK,
- original shopper image as IDENTITY ANCHOR,
- exact merchant product references.

## Product fidelity
Products can provide up to three reference views per generation. Category-specific rules cover shoes, bags, earrings, necklaces and garments. Precision-sensitive generations can use a higher-fidelity model. The generated output is checked against product references; one correction attempt is allowed when fidelity is below threshold.

## Photo guidance
The uploader gives category-aware framing instructions. Shoe try-on asks for visible feet; jewellery asks for relevant head/neck visibility; bottoms ask for lower-body visibility.
